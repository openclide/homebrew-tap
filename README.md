# Clidable Homebrew Tap

[Clidable](https://github.com/openclide/clidable) — CLI coding agents for everyone.

## Install

```sh
brew install openclide/tap/clidable
```

Then run:

```sh
clidable
```

The app serves its UI and API on port 7878 by default.

> Renamed from `clidable-server` to `clidable` — the command you type. A
> `tap_migrations.json` entry redirects the old name, so
> `brew install openclide/tap/clidable-server` still resolves here.

## Formulae

|---|---|
| `clidable` | The Clidable server / CLI (macOS arm64/x64, Linux arm64/x64) |
