# Clidable Homebrew Tap

[Clidable](https://github.com/openclide/clidable) — CLI coding agents for everyone.

## Install

```sh
brew install openclide/tap/clidable-server
```

Then run:

```sh
clidable-server
```

The app serves its UI and API on port 7878 by default.

## Formulae

| Formula | Description |
|---|---|
| `clidable-server` | The Clidable server binary (macOS arm64/x64, Linux arm64/x64) |

Issues and source: <https://github.com/openclide/clidable>
